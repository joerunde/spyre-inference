Sampled-row gather on MRV2

This is a stopgap plan for keeping the decoder's hidden states on Spyre through sampling in the V2 model runner. It assumes the V1 runner is gone and that torch-spyre is bumped past #5978 (native aten::index.Tensor). It replaces both #1357 and #1595. The full comparison of those two is in the earlier review.

Plan

A tensor subclass scoped to one sample() call

Upstream MRV2's GPUModelRunner.sample(hidden_states, input_batch, grammar_output) starts with hidden_states[input_batch.logits_indices], then calls compute_logits. That call has the tensor and its index together, so the Spyre runner can override it. The override wraps the hidden states for that one call and redirects only that one index.

# spyre_inference/v1/worker/spyre/model_runner.py (sketch)
def sample(self, hidden_states, input_batch, grammar_output):
    if hidden_states.device.type == "spyre" and self.batch_sharder is None:
        hidden_states = _SampleRows.wrap(
            hidden_states,
            index=input_batch.logits_indices,
            padded_rows=next_bucket(input_batch.logits_indices.numel(), self.row_buckets),
            decode=self.cudagraph_manager.is_pure_decode(input_batch),
        )
    return super().sample(hidden_states, input_batch, grammar_output)

class _SampleRows(torch.Tensor):
    @classmethod
    def __torch_function__(cls, func, types, args=(), kwargs=None):
        if func is torch.Tensor.__getitem__ and isinstance(args[0], cls) and args[1] is args[0]._index:
            return args[0]._gather()
        with torch._C.DisableTorchFunctionSubclass():
            return func(*args, **(kwargs or {}))

    def _gather(self):
        src, idx, num_rows = self.as_subclass(torch.Tensor), self._index, self._index.numel()
        if num_rows == 0:
            return src[:0]
        if self._decode:
            rows = src                                   # padded body: one row per request
        else:
            idx = torch.cat([idx, idx[-1:].expand(self._padded_rows - num_rows)])
            rows = src[idx]                              # native aten::index.Tensor
        out = rows[:num_rows]
        out._spyre_padded_rows = rows                    # compute_logits projects this
        return out
Wrapper
Generate models keep their hidden states on Spyre. compute_logits projects _spyre_padded_rows when the tag is present and trims the logits back to R rows. Any other input, such as a prompt-logprob slice, takes the existing host path.
Decode
The shortcut comes from the bucket manager's own decision: a pure-decode batch whose padded token count equals the row bucket. It isn't inferred from the index. is_pure_decode is a placeholder name; the real field gets settled in bring-up.
Warmup
warmup.run compiles the native gather at each row bucket that fits in each body bucket, and the lm_head on that output layout, as both PRs do today.
Guard
After warmup, an untagged Spyre tensor reaching a generate-mode compute_logits logs a warning once. A test fails on it. This turns every silent fallback below into a visible one.
Host path
Kept for eager runs (no bucketer), prompt logprobs, and SPYRE_SAMPLE_ROWS_ON_DEVICE=0. Batch-sharded sampling gathers with a different index, so the wrap skips it. It stays correct, just without the padding.
Exit
Upstream refactors sample()'s logits step into an overridable method, for example compute_sample_logits(hidden_states, input_batch). Spyre then overrides that method with the same pad, gather and trim, and the subclass is deleted.
Robustness

What happens when upstream changes

The #1357 and #1595 columns describe those PRs as written, on the V1 runner. The last column is this plan on MRV2. The right fallback is the host path, which is slower but correct. The wrong one is a padded value reaching code that expects the real one.

Every failure mode in the last column falls back to a correct path and is caught by the post-warmup warning. The cost is that it depends on upstream keeping both sample() and the hidden_states[input_batch.logits_indices] expression. The upstream hook in "Exit" removes that dependency.
