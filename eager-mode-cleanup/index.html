Fully eager attention on Spyre stays blocked on torch-spyre#4334. A probe tracks it, and CPU + eager stays tested.

Estimated savings
  • Attention suite: ≈ 91 → ≈ 36–41 shard-min (about −50 to −55), so ATTN_SHARDS could go from 8 to about 4.
  • Attention-smoke tier: about −3 min (token-major cases are ~196 s of 398 s).

What's lost

  • Fully eager attention on Spyre until torch-spyre#4334 is fixed. CPU + eager still works.
  • No model or serving feature. ALiBi is already gone (#1461). Every other attention feature (fp8, sinks, SWA, soft-cap, GQA/MQA/MHA, batched decode) already runs on head-major.
